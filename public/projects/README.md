# Project screenshots

Drop your screenshots here with these exact filenames (referenced from `lib/data.js`):

- medicare.png
- ecommerce.png
- student-management.png
- mealdb.png

Any common web image format works (.png, .jpg, .webp) — just update the
`image` path in `lib/data.js` to match whatever filename/extension you use.
Recommended aspect ratio: roughly 16:9 (e.g. 1200×675px) since the card crops
to `object-fit: cover`.
